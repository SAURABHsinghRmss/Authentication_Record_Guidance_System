# Authentication, Record and Guidance System

## Structure Overview
- `dependencies/`: Local Python wheels, node cache, and quantized AI model weights.
- `backend/`: FastAPI core application, SQLAlchemy ORM models, and workers.
- `frontend/`: Cyber-glassmorphism Lit Web Components and Alpine.js views.
- `ai_engine/`: Biometric pipelines and dense vector RAG modules.
- `infrastructure/`: Docker Compose configurations and database setup.

## Execution
1. Grant execution permission: `chmod +x start_system.sh`
2. Run the system: `./start_system.sh`
